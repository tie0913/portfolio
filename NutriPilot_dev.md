# NutriPilot – AI-powered Nutrition Platform

## Overview

NutriPilot is a full-stack application that generates personalized nutrition recommendations based on user health data and food images.

This project demonstrates hands-on full-stack development and end-to-end system implementation.

---

## My Role

Worked as a full-stack developer, independently responsible for backend implementation, API design, system integration, and deployment.

---

## Key Implementation

* Developed backend services using FastAPI to handle user requests and data processing
* Built RESTful APIs for authentication, session management, and nutrition data handling
* Implemented AI inference workflow to generate personalized nutrition recommendations
* Designed image processing pipeline to compress inputs and reduce AI inference cost
* Used MongoDB for storing user data, health profiles, and generated results
* Integrated frontend (Flutter) with backend services to deliver end-to-end functionality
* Deployed the application using Docker Compose for a consistent runtime environment

---

## Engineering Challenges

**Stateless System Design**
Designed a stateless backend architecture to simplify scaling and avoid maintaining long-lived session state.

**AI Cost Optimization**
Optimized image size and request payload to reduce token usage while maintaining response quality.

---

## Results

* Delivered a fully functional end-to-end system integrating frontend, backend, and AI services
* Successfully deployed and tested in a containerized environment
* Achieved stable performance for user requests and AI processing workflows

---

## Tech Stack

* Backend: FastAPI (Python)
* Frontend: Flutter
* Database: MongoDB
